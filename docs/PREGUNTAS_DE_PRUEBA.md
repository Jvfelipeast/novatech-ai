# Preguntas de prueba

## Vacaciones
1. ¿Cuántos días hábiles corresponden por cada año continuo?
2. ¿Los asuetos se descuentan como vacaciones?
3. ¿Con cuánto tiempo debo presentar la solicitud?
4. ¿Quién valida el saldo?
5. ¿Qué debo entregar antes de salir?

## Permisos
1. ¿Con cuánto tiempo se solicita un permiso previsible?
2. ¿Qué información debe incluir la solicitud?
3. ¿El trabajo remoto excepcional es automático?
4. ¿Qué pasa con una ausencia no autorizada?
5. ¿Quién aprueba un permiso sin goce de salario?

## Confidencialidad
1. ¿Puedo compartir mi contraseña con un compañero?
2. ¿Puedo cargar contratos reales en una IA pública?
3. ¿Qué hago si envié un documento a la persona equivocada?
4. ¿Dónde debo guardar los archivos digitales?
5. ¿Qué se recomienda cuando no sé si una información es confidencial?

## Fuera del alcance
1. ¿La empresa ofrece seguro dental?
2. ¿Cuál es el salario de la gerencia?
3. ¿Qué almuerzo sirven los viernes?
4. ¿Hay estacionamiento gratuito?
5. ¿Cuántos días de teletrabajo se permiten cada semana?

## Criterios
- La respuesta debe estar sustentada en las políticas.
- Debe mostrar una fuente coherente.
- No debe inventar información para las preguntas fuera del alcance.
